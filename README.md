# Cosmic Health

> An interactive health-monitoring dashboard designed to help astronauts
track and understand changes in their health during long-duration missions.
> 

##  About

Cosmic Health is an interactive dashboard designed to help astraunauts track, assess, and understand changes in their health during long duration space missions. With daily check ins and a built-in ai assistant astraunauts can keep track of their health during long duration missions.

##  Features

-  Daily health check-ins
-  Musculoskeletal monitoring
-  Cardiovascular monitoring
-  Respiratory monitoring
-  Mental & behavioral health
-  Sleep monitoring
-  Health analysis and history
-  AI health assistant
-  Early risk identification

##  How It Works

1. Start a daily check-in
2. Select relevant health indicators
3. Select symptoms/body areas
4. Rate severity
5. Receive a health analysis
6. Review precautions and recommendations
7. Ask the AI assistant questions
8. Track changes over time
